      내 캘린더 앱에 구독하기

      한 번만 구독해 두면 새 마감일과 학사일정이 구글·아이폰 캘린더에 자동으로 들어와요. 매번 '추가'를 누를 필요가 없어요.

      • 구글 캘린더 (PC) — 왼쪽 '다른 캘린더' 옆 + → URL로 추가 → 주소 붙여넣기
      • 아이폰·맥 — 아래 '애플 캘린더로 열기' 누르면 바로 구독 창이 떠요
      • 안드로이드 — PC 구글 캘린더에서 한 번 추가하면 폰에도 같이 떠요

      업데이트는 캘린더 앱이 정하는 주기(보통 몇 시간~하루)로 돼요. 사이트를 GitHub에 올린 뒤부터 동작해요.

      앱처럼 아이콘으로 열 수 있어요. 알림 기능이 붙으면 아이폰은 이 방식으로 추가해야 알림이 와요.
